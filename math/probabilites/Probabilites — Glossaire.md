#math #probabilites #glossaire #référence

| Terme | Définition |
|-------|-----------|
| **Moyenne** | Somme des valeurs divisée par leur nombre ; sensible aux valeurs extrêmes. |
| **Médiane** | Valeur centrale d'un échantillon trié ; robuste aux valeurs extrêmes. |
| **Quartile (Q1, Q3)** | Valeurs séparant respectivement les 25% et 75% inférieurs d'un échantillon trié. |
| **IQR (Inter-Quartile Range)** | `Q3 − Q1`, mesure de dispersion peu sensible aux outliers. |
| **Variance** | Mesure de dispersion autour de la moyenne, exprimée au carré de l'unité d'origine. |
| **Écart-type** | Racine carrée de la variance, exprimée dans l'unité d'origine. |
| **Correction de Bessel (n−1)** | Division par `n−1` plutôt que `n` pour obtenir un estimateur non biaisé de la variance d'un échantillon. |
| **Variable aléatoire** | Fonction associant une valeur numérique à chaque issue possible d'une expérience aléatoire. |
| **Espérance E[X]** | Moyenne théorique d'une variable aléatoire, pondérée par les probabilités de chaque issue. |
| **Loi des grands nombres** | Convergence de la moyenne empirique vers l'espérance théorique quand le nombre d'observations augmente. |
| **Loi de Bernoulli** | Distribution à deux issues (succès/échec) avec probabilité de succès `p`. |
| **Loi binomiale** | Distribution du nombre de succès sur `n` répétitions indépendantes d'une expérience de Bernoulli. |
| **Loi de Poisson** | Distribution du nombre d'événements rares sur un intervalle donné, paramétrée par `λ` (taux moyen). |
| **Loi normale (gaussienne)** | Distribution continue en cloche, caractérisée par sa moyenne `μ` et son écart-type `σ`. |
| **Théorème central limite (TCL)** | Convergence de la moyenne d'un grand nombre de variables i.i.d. vers une loi normale, quelle que soit leur distribution d'origine. |
| **Probabilité conditionnelle** | Probabilité d'un événement sachant qu'un autre événement s'est déjà produit, notée `P(A\|B)`. |
| **Théorème de Bayes** | Formule permettant d'inverser le sens d'une probabilité conditionnelle. |
| **Prior / Posterior** | Probabilité estimée avant (prior) et après (posterior) prise en compte de nouvelles données, dans le cadre bayésien. |
| **Covariance** | Mesure de la variation conjointe de deux variables, dépendante de leurs unités. |
| **Corrélation (Pearson)** | Covariance normalisée, comprise entre -1 et 1, indépendante des unités. |
| **Softmax** | Fonction transformant un vecteur de scores bruts en une distribution de probabilité valide. |
| **Température (softmax)** | Paramètre ajustant la "netteté" d'une distribution softmax. |
| **Similarité cosinus** | Mesure de proximité entre deux vecteurs basée sur l'angle qui les sépare, indépendante de leur magnitude. |
| **Perplexité** | Métrique d'évaluation des modèles de langage, exponentielle de l'entropie croisée moyenne. |
| **Hypothèse nulle (H₀)** | Position par défaut testée dans un test d'hypothèse, généralement "aucun effet/différence". |
| **p-value** | Probabilité d'observer un résultat au moins aussi extrême que celui obtenu, en supposant H₀ vraie. |
| **t-test** | Test statistique comparant une ou deux moyennes, adapté aux petits échantillons. |
| **Test du chi² (khi-deux)** | Test comparant des fréquences observées à des fréquences attendues, souvent pour tester l'indépendance entre variables catégorielles. |
| **Intervalle de confiance** | Fourchette de valeurs plausibles pour un paramètre inconnu, associée à un niveau de confiance donné. |
| **Erreur de type I** | Rejeter H₀ alors qu'elle est vraie (faux positif). |
| **Erreur de type II** | Ne pas rejeter H₀ alors qu'elle est fausse (faux négatif). |
