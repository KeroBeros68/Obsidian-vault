## 🪤 Piège 1 — Faire confiance à tout ce que dit l'IA

```
❌ "L'IA a dit X donc c'est vrai"
✅ "L'IA a dit X, je vérifie sur une source fiable avant d'utiliser cette info"
```

> [!warning] Hallucination
> Un LLM peut inventer une statistique, une citation, un nom d'auteur ou une loi avec une totale assurance. Il ne "sait" pas qu'il se trompe.

---

## 🪤 Piège 2 — Prompt trop vague

```
❌ "Améliore ça"
❌ "Fais-moi un email"
❌ "Parle-moi du marketing"

✅ "Rédige un email de relance client, ton professionnel, 3 paragraphes, pour
    quelqu'un qui n'a pas payé sa facture depuis 30 jours"
```

> [!tip] Mémo
> L'IA ne lit pas dans tes pensées. Plus tu es précis, plus le résultat est utile. Ajoute toujours : pour qui, dans quel but, sous quel format.

---

## 🪤 Piège 3 — Utiliser le mauvais outil

```
❌ Utiliser un LLM pour connaître les actualités d'aujourd'hui (sans recherche web)
❌ Utiliser Midjourney pour rédiger un contrat
❌ Utiliser ChatGPT sans Perplexity pour des recherches avec sources vérifiables
```

> [!tip] Mémo
> Texte/analyse → LLM. Image → Midjourney/DALL·E. Recherche récente → Perplexity. Automatisation → Zapier/Make.

---

## 🪤 Piège 4 — Oublier la date de coupure

L'IA a été entraînée jusqu'à une certaine date. Elle ne connaît pas les événements récents.

```
❌ "Quelle est la dernière version de [logiciel] ?"  → réponse potentiellement obsolète
✅ Utiliser Perplexity ou activer la recherche web pour tout ce qui est récent
```

> [!warning]
> Les prix, les lois, les actualités, les nouvelles versions de logiciels changent. Toujours vérifier pour des infos sensibles au temps.

---

## 🪤 Piège 5 — Abandonner après le premier résultat

```
❌ Résultat moyen → "cet outil est nul"
✅ Résultat moyen → itérer :
    "C'est bien mais rends-le plus court"
    "Refais la partie 2 avec un ton plus dynamique"
    "Donne-moi 3 autres versions"
```

> [!tip] Mémo
> Le prompting est un dialogue, pas une commande unique. 80% de la valeur vient de l'itération.

---

## 🪤 Piège 6 — Donner des infos sensibles à l'IA

```
❌ Coller un contrat confidentiel, des données clients, des mots de passe
✅ Anonymiser ou remplacer par des données fictives avant de partager
```

> [!warning] Confidentialité
> Les conversations peuvent être utilisées pour améliorer les modèles (selon les conditions d'utilisation). Ne jamais partager d'informations réellement confidentielles ou personnelles.

---

## 🪤 Piège 7 — Ne pas donner de contexte sur soi

```
❌ "Donne-moi des conseils pour mon entreprise"
✅ "Je suis freelance en design graphique, 3 ans d'expérience, clientèle PME
    locales, je veux développer mon chiffre d'affaires. Donne-moi des conseils."
```

> [!tip] Mémo
> L'IA n'a aucune information sur toi. Chaque contexte que tu fournis est un levier pour personnaliser la réponse.

---

## Récapitulatif rapide

| Piège | Solution |
|---|---|
| Faire confiance aveuglément | Toujours vérifier les faits importants |
| Prompt vague | Rôle + Contexte + Tâche + Format + Contraintes |
| Mauvais outil | Choisir selon la tâche (texte, image, recherche...) |
| Info obsolète | Utiliser Perplexity ou la recherche web intégrée |
| Abandonner trop vite | Itérer et reformuler |
| Données sensibles | Anonymiser avant de partager |
| Pas de contexte personnel | Toujours se présenter et décrire sa situation |
