```
DSPy         : IA 01-03 → RAG → Agents → DSPy 01-04 → 05-07 → 08-10

Structured Output : IA 01-03 → TR 06 → CD 01-02 → CD 03-06 (librairies) → CD 07-09 (intégrations)

Ollama       : IA 01-03 → Ollama 00 → 01 → 02 → 03 → 04 → 05

LiteLLM      : IA 01-03 → LiteLLM 00 → 01 → 02 → 03 → 04 → 05 → 06

PydanticAI   : IA 01-03 → Agents 01-03 → LiteLLM 06 → PydanticAI 00 → 01 → 02

Qdrant       : RAG 01 → 02 → Qdrant 01 → 02 → 03 → 04 → 05

Vers le ML : Algèbre linéaire → NumPy → Pandas → ML (scikit-learn)
```
