#ia #outils #pratique

## Les grands outils IA

Choisir le bon outil pour la bonne tâche est aussi important que de bien l'utiliser.

## Texte & Conversation (LLM)

| Outil | Créateur | Points forts |
|---|---|---|
| **Claude** | Anthropic | Raisonnement, nuance, longues analyses, fiabilité |
| **ChatGPT** | OpenAI | Très polyvalent, plugins, génération d'images intégrée |
| **Gemini** | Google | Intégré à Google Workspace, recherche web native |
| **Mistral** | Mistral AI 🇫🇷 | Open-source, rapide, excellent en français |
| **Perplexity** | Perplexity AI | Recherche web en temps réel avec sources citées |

> [!tip] Quel LLM choisir ?
> Pour débuter : Claude ou ChatGPT. Pour des recherches avec sources : Perplexity. Pour du français spécifique : Mistral.

## Images

| Outil | Points forts |
|---|---|
| **Midjourney** | Qualité artistique exceptionnelle |
| **DALL·E 3** | Intégré à ChatGPT, facile d'accès |
| **Stable Diffusion** | Gratuit, open-source, très personnalisable |
| **Adobe Firefly** | Intégré à Creative Cloud, légalement sûr |

## Audio & Voix

| Outil | Usage |
|---|---|
| **ElevenLabs** | Clonage de voix, text-to-speech ultra-réaliste |
| **Suno** | Génération de musique complète à partir d'un texte |
| **Whisper** (OpenAI) | Transcription audio → texte (très précis) |

## Vidéo

| Outil | Usage |
|---|---|
| **Runway** | Génération et édition vidéo par IA |
| **Kling / Sora** | Génération vidéo haute qualité |
| **HeyGen** | Avatars vidéo, traduction avec lip sync |

## Automatisation & Productivité

| Outil | Usage |
|---|---|
| **Notion AI** | Écriture, résumés, brainstorm dans Notion |
| **Zapier / Make** | Automatiser des tâches entre apps avec IA |
| **GitHub Copilot** | Assistant de code dans ton éditeur |

## Règle de sélection

```
Tâche
  ↓
Est-ce du texte / de l'analyse / du code ?  → LLM (Claude, ChatGPT)
Est-ce une image à créer ?                  → Midjourney, DALL·E
Est-ce de la voix à générer ?               → ElevenLabs
Est-ce de la musique ?                      → Suno
Est-ce une recherche récente ?              → Perplexity
Est-ce une automatisation ?                 → Zapier, Make
```

> [!warning] Ces outils évoluent vite
> Le paysage IA change tous les mois. Un outil leader aujourd'hui peut être dépassé demain. Reste curieux et surveille les nouveautés.
